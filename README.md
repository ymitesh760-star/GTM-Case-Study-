# 🥣 MilletMorn — College Case Study Website

A simple, clean, and responsive React web application for the college case study project: **MilletMorn (Ready-to-Cook Millet Breakfast Mix)**.

---

## 🚀 How to Run Locally

```bash
# 1. Install dependencies
npm install

# 2. Start the local development server
npm run dev
```

Open your browser at: **`http://localhost:3000/`**

---

## 📋 Sections Included (In Presentation Order)

1. **HOME (Hero)**
   - Logo / Name: `MilletMorn`
   - Headline: *“Quick Breakfast. Better Mornings.”*
   - Description: *“A ready-to-cook millet breakfast mix for busy mornings.”*
   - *“Buy Now”* button & 500g product pack card.

   - Target Customer Cohorts:
     - Working Professionals
     - Health-conscious Families
     - Students & Young Adults

3. **PRODUCT**
   - Product: Ready-to-Cook Millet Breakfast Mix
   - Pack Size: 500 g
   - Price: ₹169
   - Interactive *“Add to Cart”* and quantity counter.

4. **HOW IT WORKS**
   - 3 Simple Steps:
     1. Buy the product
     2. Prepare the breakfast
     3. Enjoy your meal

5. **CUSTOMER JOURNEY**
   - Simple visual flow:  
     `Awareness` ↓ `Consideration` ↓ `Purchase` ↓ `Preparation` ↓ `Consumption` ↓ `Feedback` ↓ `Repeat Purchase`

## 🛠 Tech & Design
- **Tech:** React.js, Vite, JavaScript, Tailwind CSS, Lucide React icons.
- **Design:** Clean white/cream background, deep navy (`#162D50`) & farm green (`#1E7B42`) accents, clean typography, fully responsive on laptop and mobile.
- **No Complexities:** No database, no backend, no authentication, no real payment gateway needed.
